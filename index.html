Interactive Guide

Profile simulator navigation:

  • 3D Grid View: Tap any photo thumbnail in the profile grid on the iPhone screen. The detail page will slide up from the bottom.
  • Interactive Carousel: If the post is a carousel, swipe left/right on it or click the navigation arrows inside the detail overlay.
  • Double-Tap to Like: Double-click the picture in the detail overlay to trigger a heart animation and add a like.
  • Dynamic Customizer: Customize username, bio text, logo avatar, and count indicators dynamically from the left sidebar panel.
